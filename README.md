# Digital Signal Processing (DSP) MATLAB Codes

This repository contains MATLAB programs related to Digital Signal Processing (DSP), including signal generation, convolution, correlation, Fourier transforms, and analog/digital filter design using Butterworth and Chebyshev filters.

---


# Software Requirements

- MATLAB
- MATLAB Signal Processing Toolbox

---

# How to Run

1. Open MATLAB.
2. Clone or download this repository.
3. Open any `.m` or `.mlx` file in MATLAB Editor.
4. Run the script.

---

# Topics Covered

- Continuous Time Signals
- Discrete Time Signals
- Unit Impulse Signals
- Convolution
- Correlation
- DFT & FFT
- Low Pass Filters
- High Pass Filters
- Band Pass Filters
- Band Stop Filters
- Butterworth Filters
- Chebyshev Type-1 Filters
- (For Chebysehev Type-2  Filters, you need to replace "chebye1" with "chebye2" in the code .)
